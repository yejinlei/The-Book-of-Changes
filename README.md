# 《易经》本体论三维可视化
基于Three.js构建的《易经》本体论系统，七层架构呈现从道到384爻的完整演化体系。

## 功能特性
- 🏛️ **七层本体架构**：L0元模型 → L1核心本体 → L2三易原则 → L3卦爻体系 → L4注疏传承 → L5象数义理 → L6文化外延
- ☯️ **64卦384爻全建模**：每卦每爻独立本体条目，上经32卦包含完整卦辞、彖传、象传、爻辞及白话解读
- 🎮 **Three.js 3D场景**：太极阴阳鱼、八卦环、粒子动效，可拖拽旋转缩放
- 🔄 **宇宙生成链演示**：道→一→二→四象→八卦→六十四卦→384爻，逐级推演完整过程
- 📊 **义理关系图谱**：ECharts力导向图展示本体间生成/对立/转化关系
- ⏱️ **传承时间轴**：从伏羲画卦到朱熹集大成的易学史脉络
