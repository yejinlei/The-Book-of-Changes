# 易经本体论 · The Book of Changes Ontology

以本体论方法重构《周易》符号体系与义理系统的数字人文研究站点。

## 站点结构

- **总览**：七层本体架构与核心统计
- **生成链**：道→太极→两仪→四象→八卦→六十四卦的 Three.js 三维可视化
- **卦爻体系**：八卦卡片与六十四卦网格
- **经文**：六十四卦卦爻辞阅读
- **义理**：三易原则、象数派与义理派
- **知识图谱**：ECharts 力导向关系图
- **传承**：易学传承时间轴
- **历代易学**：大师谱系 + 经典注本 + 汇评集成
  - 56 位先秦至当代易学大师
  - 37 种历代经典注本
  - 逐卦汇评：《周易集解》（汉魏至唐三十余家）＋《御纂周易折中》（朱熹《本义》、程颐《程传》、历代集说）
- **关于**：项目说明

## 目录

```
index.html                 主页面
data/yijing-commentary.js  历代易学汇评数据（64 卦汇评 + 大师谱系 + 注本）
.nojekyll                  禁用 Jekyll
```

## 技术

纯静态站点，无需构建。Three.js（三维）、ECharts（图谱）、Noto Serif SC（字体）均经 CDN 引入。

## 数据来源

- 经文与汇评：《周易集解》（唐·李鼎祚）、《御纂周易折中》（清·李光地等）
- 卦爻辞通行本
