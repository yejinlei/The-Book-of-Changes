本体设计原则：①每条三元组都可追溯到原始文献（卦爻辞、十翼、注疏原文）；②所有筮法规则（大衍、纳甲）以可计算公理表达，不硬编码结论；③学术关系区分师承 / 宗述 / 引述 / 驳斥 / 评议五类，方向严格；④文本异文多版本并列保留，不做擅断。

如何查询本本体

本站目前以静态 Turtle 文件形式提供下载，您可以使用任意 RDF 工具加载后用 SPARQL 查询。 推荐工具：Apache Jena (arq / tdb2)、rdflib (Python)、Protegé、GraphDB、Blazegraph。

# Python + rdflib 示例：列出所有汉代注家
from rdflib import Graph, Namespace
g = Graph()
g.parse("yijing-ontology.ttl", format="turtle")
YJ = Namespace("https://yejinlei.github.io/The-Book-of-Changes/ontology/yijing#")
q = """
  SELECT ?name ?work WHERE {
    ?c a yj:Commentator ;
      rdfs:label ?name ;
      yj:dynasty ?d ;
      yj:representativeWork ?work .
    FILTER(REGEX(STR(?d), "汉"))
  }
"""
for row in g.query(q, initNs={'yj': YJ}):
  print(row.name, row.work)
未来计划：本站将提供在线 SPARQL 端点（Endpoint），直接在浏览器中即可提交查询并返回 JSON/CSV。 届时可通过 https://yejinlei.github.io/The-Book-of-Changes/sparql 访问。

常用查询示例

下列每条都可以直接复制到任意 SPARQL 查询工具中运行（把命名空间 yj: 绑定到本本体 IRI 即可）。

# 1. 错卦、综卦、互卦查询：泰卦的全部卦象关系
SELECT ?rel ?targetName WHERE {
  yj:gua_10 ?rel ?target . # 泰卦 = 第11卦 (idx 10)
  ?target rdfs:label ?targetName .
  FILTER(?rel IN (yj:cuoGua, yj:zongGua, yj:huGua, yj:jiaoGua))
}

# 2. 王弼的学术论敌：哪些人驳斥王弼
SELECT ?critic ?name WHERE {
  ?critic yj:criticizes yj:zj_wangbi ; rdfs:label ?name .
}

# 3. 某卦某爻的全部注疏及其作者朝代
SELECT ?zjName ?zjEra ?noteText ?citation WHERE {
  ?note yj:annotates yj:gua_00_y1 ; # 乾初九
        yj:commentaryNoteText ?noteText ;
        yj:sourceCitation ?citation ;
        yj:annotatedBy ?zj .
  ?zj rdfs:label ?zjName ; yj:dynasty ?zjEra .
} ORDER BY ?zjEra

# 4. 帛书本与通行本卦名对照表
SELECT ?seq ?rec ?boshu WHERE {
  ?g a yj:Hexagram ;
     yj:sequenceNumber ?seq ;
     rdfs:label ?rec ;
     yj:variantReading ?boshu .
  FILTER(CONTAINS(STR(?boshu), "帛书"))
} ORDER BY ?seq
